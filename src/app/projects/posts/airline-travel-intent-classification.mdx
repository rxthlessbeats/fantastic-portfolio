## Introduction

This project implements **intent classification** for an airline travel information system. Given a user query (e.g. “show me flights from Boston to Denver”), the model predicts the intent label so downstream dialogue logic can route the request—flights, fares, ground service, and related travel information.

## Problem & dataset

**Problem:** Utterances are short and phrasing varies widely. The classifier must map text to the correct intent under **class imbalance** (e.g. `flight` dominates; rare or compound labels are hard).

**Dataset:** [ATIS](https://github.com/huggingface/datasets/blob/main/datasets/atis/README.md) (Airline Travel Information System), stored as **Rasa NLU JSON** (`train.json`, `test.json`) with `text`, `intent`, and optional `entities` for slot spans.

Preprocessing highlights:

- Lowercasing, whitespace normalization, multi-word collapse
- **Shared-intent filter** — keep only intents present in both train and test splits
- **Stratified** train/validation split; singleton intents kept in train
- **Entity masking** — replace cities, airlines, airports, dates, times, and numerics with typed placeholders (e.g. `[city]`, `[airline]`) so models learn intent patterns rather than memorizing entities

## Key takeaways

- **Entity masking** (~10% gain) and **TF-IDF bigrams** helped most; **word-level TextCNN** was best (96.2% acc, 70.1% macro-F1). **Class weighting** improved rare-intent recall.
- **Stop-word removal**, **BPE/char tokenization**, and **focal loss + class weights** underperformed. Random deletion helped TF-IDF but hurt CNNs.
- **Macro-F1** matters more than accuracy here: weighted F1 stays high on `flight`, while rare/compound intents and **test-only labels** drag macro-F1 down. Preprocessing mattered as much as architecture.

## Limitations & future work

**Limitations:** Test labels missing from training; few shots per minority class; bag-of-words / local-CNN limits on semantic overlap (`flight` vs `airfare`). Intent-only—no slot filling.

**Future work:** Matched-label splits + template augmentation for rare intents; BERT under the same masking and metrics; intent-description models for unseen classes.
